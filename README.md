# Homeland

Projeto desenvolvido durante a Sprint 6 da formação em Desenvolvimento Web da TripleTen.

O objetivo deste projeto é criar uma página web responsiva que apresente histórias, imagens e localidades que representam as origens de diferentes pessoas ao redor do mundo. O foco principal está na construção de layouts modernos utilizando HTML e CSS, com atenção especial à responsividade e à organização do código.

## ✨ Funcionalidades

### Header

- Exibição da identidade visual do projeto através do logotipo.
- Layout centralizado e adaptável.

### Hero Section

- Título principal do projeto.
- Texto introdutório.
- Imagem de destaque.
- Layout responsivo para diferentes dispositivos.

### Photo Grid

Galeria construída com CSS Grid para exibir imagens relacionadas aos locais apresentados no projeto.

Características:

- Organização automática dos elementos.
- Adaptação para diferentes resoluções.
- Melhor aproveitamento do espaço disponível na tela.

### Places

Seção composta por diferentes localidades apresentadas através de:

- Nome da cidade ou região.
- Imagem representativa.
- Créditos dos artistas ou fotógrafos.
- Texto descritivo.
- Botão para explorar mais informações.

Localidades incluídas:

- Berea
- Criccieth
- Muramvya
- Caeté (MG)

### Footer

- Informações finais do projeto.
- Encerramento visual consistente com o design da página.
